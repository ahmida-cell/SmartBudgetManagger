# SmartBudgetManager

A project for managing Budget.

## Overview
**SmartBudgetManager** is a simple budget management system designed to record, organize, and track financial entries by date, budget amount, and transaction ID.

## Project Files
- `README.md`: Project documentation and general overview.
- `budget.txt`: Text log containing dated budget records and IDs.
- `SmartBudgetManager.xlsx`: Spreadsheet file for structured budget calculations and tracking.
